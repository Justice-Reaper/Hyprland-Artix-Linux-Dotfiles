# generate-icons-font — Icons Font

Self-contained generator for `Icons Font.ttf`, the waybar icon font
Part of the Hyprland-Dotfiles repo

Everything needed to rebuild the font is in this folder, so it works straight after cloning the repo

## Contents

| File | What it is |
|---|---|
| `build-waybar-icons-font.py` | The generator, reads the SVGs in `icons/` and builds the font |
| `icons/` | The source SVGs grouped by category (battery, clock, wifi…), the alphabetical folder/file order defines the codepoints |
| `print-icons.py` | Prints every icon in the terminal (reads `icon-chars.sh` live) |
| `icon-chars.sh` | Name → codepoint map, generated by the build |

## Build

```bash
fontforge -lang=py -script build-waybar-icons-font.py
```

Writes the font to `../fonts/Icons Font.ttf` and the codepoint map to `icon-chars.sh` in this folder

Print the icons in the terminal (needs the font installed)

```bash
python3 print-icons.py
```

## Install the font system-wide

```bash
sudo cp -r ../fonts /usr/local/share
sudo fc-cache -f /usr/local/share/fonts
```

## Add or change icons

1. Drop the `.svg` into `icons/<category>/`, common sources
   - MDI / Pictogrammers (`viewBox="0 0 24 24"`) https://pictogrammers.com/library/mdi/
   - Material Symbols (`viewBox="0 -960 960 960"`) https://fonts.google.com/icons download the FILL1 (solid) variant so it matches MDI's solid style
2. Rebuild with the command above
3. The SVG filename becomes the icon name, `battery-10.svg` → `ICON_BATTERY_10`, and the Material noise (`_24dp_..._opsz24`) is stripped automatically, `alarm_24dp_E3E3E3_FILL1_wght400_GRAD0_opsz24.svg` → `ICON_ALARM_FILL1`

⚠️ Adding, removing or reordering an icon shifts every later codepoint, so check `icon-chars.sh` after each build and update anything that hardcodes codepoints (waybar config/scripts)

## Normalization applied to every glyph

- Ink height exactly 1700 units
- Left and right side bearings at 0 (advance = ink width)
- Vertically centered in the line box
- Line metrics fixed at 2048 upm (ascent 1901, descent 483, linegap 0) so the line height stays consistent
- Material Symbols are adapted to MDI by using the solid (FILL1) variant and running through the exact same normalization as MDI
